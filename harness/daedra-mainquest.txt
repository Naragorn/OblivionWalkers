# DaedraAfterMainQuest=0 (docs/walkers-spec.md 4.22a step 6): once MQ16
# (0002A38F) is completed the Daedra stop - every new side the walkers',
# Mode 1's spawn replacement off. No save after the main quest exists, so
# the run completes MQ16 by console (CompleteQuest - the flag only, none of
# the quest's stage scripts; the plugin reads TESQuest::questFlags +0x3C).
#
# The hall, the harness save, Mode 1 (tools/daedra-harness.sh mainquest 1):
# LL0Goblin100 (00084B2C) placed three times gives Daedra (the replacement

# replacement runs again with Enabled=0 and puts the entries back; the same
