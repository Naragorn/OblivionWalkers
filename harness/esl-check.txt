# The ESP as a light plugin (docs/walkers-spec.md 3, ESL; Nadi, 2026-10-28:
# "esl als erstes mit requirements zu oblivionesl und als esp"): the run's
# Linux install carries the ESL-flagged OblivionWalkers.esp
# (tools/esp-write.py --esl, build-linux/esl/) instead of the plain one,
# OblivionESL loads it as light plugin 0, so its forms are FE000xxx - the
# console lines below name the walker as FE000801. OblivionWalkers.log should
# read "Walkers: OblivionWalkers.esp is at FE000000 (a light plugin,
# OblivionESL), 64 walker creatures found", the horde and news configured,
# "Grab: 6 of 6 grab idles found", the spawn lists replaced, and the test
# grab as in grab-anims.txt; Oblivion/OblivionESL.log names the plugin.
# The harness save was made with the plain ESP: whatever it holds of
# Walkers (not checked) is lost under the ESL variant - the run shows the
# plugin finding the light ESP, not a save's migration.
#
# Runs on OBVR's harness, from the OBVR folder (the ESL variant copied in by
# hand before, the plain ESP back after):
#   python3 tools/hand-script-run.py ../OblivionWalkers/harness/esl-check.txt --headless \
#       --artifact-root ../OblivionWalkers/artifacts/hand-script
