# MOO does not raise a dead walker in one of MOO's own looks (docs/walkers-spec.md
# 4.1 "MOO's looks" and 7a; Nadi, 2026-10-27: "go"): as moo-stay-down.txt,
# with the ESP's 0x91E (MOO's default set, model MOO\zombie\skeleton.nif)
# in place of 0x801 (Creatures\Zombie\Skeleton.nif). MOO's death handler
# looks for "\Zombie\Skeleton.nif" in the model path, so it should give
# this walker its token too; the plugin takes token and brain off every dead
# walker by its base. With [Zombies] BlockMooResurrect=0 (the control) the
# walker stands again, "0 dead"; with 1 (the default) it lies, "1 dead", and
# the plugin's log reads "MOO: walker ... dead - MOO's token and brain taken".
#
# Results 2026-10-27 (artifacts/hand-script/moo-stay-down-moo-look/):
#   07:59 (20261027-075958) PASS, BlockMooResurrect=0: dead at the dead to
#   t45 marks, up again at t60, then at the player (46 units) - MOO does
#   raise a walker in its own look.
#   08:02 (20261027-080233) PASS, BlockMooResurrect=1: "MOO: walker FF000EE7
#   dead - MOO's token and brain taken", dead at every mark to the end.
#
# Runs on OBVR's harness, from the OBVR folder:
#   python3 tools/hand-script-run.py ../OblivionWalkers/harness/moo-stay-down-moo-look.txt --headless \
#       --artifact-root ../OblivionWalkers/artifacts/hand-script

ini Hands Enabled=1
ini Debug GripTrace=0
ini Performance Enabled=0
console-at ready set MOO.ini_zombie_brain to 0
console-at ready set MOO.ini_zombie_resurrect to 100
console-at ready tgm
console-at ready player.placeatme {form:OblivionWalkers.esp:91E} 1
console-at placed set MOO.ini_zombie_brain to 0
console-at placed set MOO.ini_zombie_resurrect to 100
console-at placed player.setangle z 0
console-at placed {actor}.moveto player 0 300 0
console-at moved {actor}.kill

expect HandScript: finished
reject HandScript: WARNING

wait 12
right pos 0.20 -0.40 -0.30
left pos -0.20 -0.40 -0.30
wait 1
mark ready
wait 6
mark placed
wait 2
mark moved
wait 5
mark dead
wait 15
mark t15
wait 15
mark t30
wait 15
mark t45
wait 15
mark t60
wait 10
mark end
wait 1
