# The whole siege in one run (docs/walkers-spec.md 4.12; Nadi, 2026-11-04:
# "kannst du größeres siege harness bauen"). Run it through
# tools/siege-harness.sh, which gives the plugin INI the [Siege] lines this
# needs, puts the live INI back afterwards and checks OblivionWalkers.log:
#
#   [Siege] TestGate=1 ChancePerDayPercent=100 WalkersMin=80 WalkersMax=80
#           GuardKillsPerHour=2
#
# 1. ready     Anvil Castle Gate besieged by the test switch, its outer door
#              locked, Anvil's rumor 1, the Courier on "Anvil Besieged!"
# 2. visit     the player 500 units before Anvil Castle Gate: 24 of its 80
#              walkers come out, the gate guards come out for them
# 3. kill1     killall (Dismemberment=0: every kill ends one) - they count off,
#              the rest come out
# 4. saved     a save with Anvil's siege on, WalkersSiegeFull
# 5. away      into Benirus Manor (an interior): the walkers back in the pool
# 6. loaded    the save loaded: the session's lock given back, the siege read
#              from the co-save, its door locked again, the walkers out again
# 7. leave     into Benirus Manor again: back in the pool
# 8. nextday   GameDaysPassed to 5: four days away end Anvil's siege by the
#              guards' toll (gate unlocked, rumor 0, "lifted" edition), and
#              the day's roll at 100 percent besieges the seven other cities
# 9. toll      GameDaysPassed to 7: two days more end those seven - every gate
#              unlocked (Anvil pauses until its day 8, the others until 10)
#
# The first run (2026-11-04 20:21) had the day's jump before the visit: the
# toll of four days ended Anvil's siege before the player came - right, but
# nothing to see at the gate; this order shows both.
#
# Runs on OBVR's harness, from the OBVR folder - through the wrapper:
#   ../OblivionWalkers/tools/siege-harness.sh

ini Hands Enabled=1
ini Hands Dismemberment=0
console-at ready tgm
console-at visit player.moveto 00006FBA 0 -500 0
console-at kill1 killall
console-at saved save WalkersSiegeFull
console-at away coc AnvilBenirusManor
console-at loaded load WalkersSiegeFull
console-at leave coc AnvilBenirusManor
console-at nextday set GameDaysPassed to 5
console-at toll set GameDaysPassed to 7

expect HandScript: finished
reject HandScript: WARNING

wait 12
wait 1
mark ready
wait 8
mark visit
wait 20
mark kill1
wait 12
mark saved
wait 4
mark away
wait 8
mark loaded
wait 25
mark leave
wait 8
mark nextday
wait 8
mark toll
wait 8
mark end
wait 1
